## 最简单的使用方式

双击目录里的 **`启动海晏河清.command`**，保持打开的终端运行。它会打开网页；如果服务已经启动，会直接打开现有服务。

1. 在“我的”创建独立网页账号，阅读并勾选协议，完成本站自托管 ALTCHA 防刷验证。密码接受任意非空内容（最多 128 字符）。
2. 首页查看天津天气，可切换北京，或主动定位选择附近城市。网页只读服务器缓存，后台定时抓取两城。
3. 生态导览浏览天津、北京地图，筛选河湖、公园、校园和步道地标。
4. 智慧识别上传花卉或河道照片，使用真实本机模型；结果可继续交给 AI 解读。
5. 科普智游阅读现有文章与路线，登录后写博客草稿并送审、评论和举报；文章与评论经管理员审核后公开。
6. 铃铛左侧快捷入口或“我的 → 外观与主题”切换森系自然、纪实自然志、山水测绘册、深色模式。

本机账号与小程序账号分别保存。此项目复制了公开资料和业务代码，未导入云端用户、私有照片或个人记录。

## 与微信版对应的适配

| 微信版能力 | 本地网页版 |
| --- | --- |
| 微信登录 | 本机邮箱/用户名与密码，安全会话 Cookie |
| wx.getFuzzyLocation / getLocation | 浏览器主动定位；仅按必要场景使用 |
| wx.chooseLocation | 网页地图选点与公开地点选择 |
| wx.openLocation | 具备核验条件的地点使用地图服务导航链接 |
| 微信订阅消息 | 一次站内通知；需要本机服务运行，关闭期间的到期提醒在重新启动后补生成 |
| 微信内容安全审核 | 保留能力闸门；本机未伪造 msgSecCheck 通过或公开用户原稿 |
| 云数据库 / 私有存储 | 独立 SQLite 数据库 / 本机私有目录 |

天气预约中的 DeepSeek 只生成待核对草稿，必须另行确认。本版不会发送微信、短信或邮件。语音播放接口与能力检测保留，但当前资料没有配置授权音频。资料反馈公开发布所需外部安全能力保持关闭；私人草稿可保存与修改，普通意见反馈可提交、编辑待处理内容并查看答复。已有代码入口不等于公开能力已启用。

## 密钥和预算

当前可用的 DeepSeek、和风天气凭据已经安全复用到 **`.private/local.env`**，仅由后端读取。浏览器和公开源文件不包含这些密钥。

- 腾讯地图网页 Key 已配置为 `TENCENT_MAP_JS_KEY`；浏览器地图必然使用它，以控制台域名白名单限制使用范围。它不入源码/Git，其他服务端密钥不向浏览器提供。
- 用户于 2026-10-08 确认网页与小程序 **各 15,000 次/月**。网页仅两城后台抓取，正常约 4,712 次/31天；本机后台关闭，不额外定时抓取。配额账本同时约束自然月与保留的滚动日桶。实际部署验证见升级记录。
- 天气不接入热带气旋、海洋、辐照产品。计数保存在数据库，失败请求也记账；不要通过删除数据库重置预算。
- 新网页 DeepSeek 全局每天最多 30 次尝试、60,000 Token 预算，各业务板块保留每用户日额度。使用量记录是内部账本，费用以提供方账单为准。
- 邮件参数仍留空；天气预约产生站内通知，不宣称提供邮件、短信或浏览器关闭后的系统推送。

`.env.example` 只列配置名，含密钥的真实环境文件位于 `.private`，权限为 600。私有目录权限为 700。

## 开发与检查

需要 Node.js 20.19 或更新版本。当前机器所需依赖已安装。

```sh
cd /Users/liu/Desktop/hyhq
npm test
npm run build
npm start
```

开发模式：先停止已有服务，再运行 `npm run dev`，打开[开发网页](http://127.0.0.1:5178)。前端更改自动更新，API 代理到 8787。也可以双击 `开发模式.command`。

第一次从纯源码安装时：

```sh
npm --prefix backend ci
npm --prefix frontend ci
node backend/bootstrap.cjs
npm run build
npm start
```

真实模型和密钥属于私有运行材料，纯源码安装不自动下载或捏造；缺少它们时对应功能明确不可用。

## 数据保存与部署

个人数据重启后保留。若需备份，先停止服务，再完整复制 `.private` 目录；备份含凭据及个人记录，应继续仅在自己的设备安全保存。

本机默认服务绑定回环地址。生产站点已部署到 `https://greatdata.asia`，由 Nginx 反向代理并强制 HTTPS，使用 Let’s Encrypt 自动续期证书及 Secure 会话 Cookie。生产服务运行在独立的 systemd 单元和目录，数据库、模型、环境密钥与发布文件分开保存；服务器管理员登录信息位于本机 `.private/server-admin-credentials.md`，权限仅当前用户可读。旧服务器版本和数据保留在原目录，旧服务已停止并禁用自启。
