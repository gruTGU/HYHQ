# 公开科普与漫步路线资料包

采集日期：2026-09-23。内容经过公开网页检索、正文核读、原创整理与人工核对，以固定离线 JSON 保存。小程序读取数据库，不在用户打开页面时抓取来源网站。

## 内容

- `eco_notes_part1.json`：植物 8 篇、水环境 7 篇。
- `eco_notes_part2.json`：绿色生活 8 篇、生态智游 7 篇。
- `walking_routes.json`：天津 15 条、北京 15 条，包含区域与真实地点节点。
- 共新增 **30 篇科普手记 + 30 条漫步路线**；不会替换原有种子文章或管理员发布的内容。

每项保存来源标题、完整 HTTPS 地址、发布机构与查阅日期。正文为有限事实要点的改写及原创观察建议，不复制整篇文章、官方照片或地图。来源不是对路线当前开放、连续通行、预约或无障碍条件的保证；引用历史资料时不冒充实时公告。

## 入库

在仓库根目录运行；命令读取当前后端环境配置，不需要将凭据写进命令或 Git。

```sh
scripts/manage.sh migrate
scripts/manage.sh import_public_knowledge
scripts/manage.sh import_public_knowledge --apply
scripts/manage.sh import_public_knowledge
```

第二步只校验并显示新增/已有数量；第三步才写入；第四步应显示新增 0。应用前应备份现有 `ecology.Region`、`ecology.Place`、`knowledge.Content`、`knowledge.Route`、`knowledge.RouteStop` 表。本批本机备份保存在被 Git 忽略的 `.runtime/content-backups/`。

- 全批校验失败不写库；写入异常由事务整批回滚。
- 同 slug 已有文章、路线和节点均保留，包括管理员修改、取消发布或删除的节点；这不是覆盖更新命令。
- 同 slug 区域或地点身份冲突会终止，避免错连示范区域或其他地点。
- 重复标题、同一区域内同名地点、换顺序凑出的重复路线、缺失/跨区域节点、过长来源字段均会被拒绝。
- 真实城市区域使用 `is_demo=false`，但不生成坐标、底图、水体观测或实时导航；非步道的桥、亭、馆舍等归为“地标与停留点”。
- 新资料需先整理审核再导入；导入器不自动抓网页、不接受网页里的指令，也不随来源变更自动改写已发布内容。
