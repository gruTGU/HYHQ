## 签名图片有效期问题与修复

开发者工具重编译后，两张测绘背景素材报加载失败。诊断时，旧缓存记录声称地址有效至 07:20 UTC，但 06:48 UTC 实际读取已返回 **HTTP 403**；同一时刻重新获取的地址均返回 **HTTP 200**，文件分别为 36,679 和 254,804 字节。改为原生 image 的临时试验同样失败，已经撤回；因此没有将问题定为 CSS 背景或样式变量。

源码修复：

- 后端请求签名时长及缓存上限设为 **300 秒**，保留原有 **60 秒**安全余量；正常返回有效期最多为 4 分钟，供应商较短的有效期继续优先。
- 即使 SDK 未返回 `maxAge`，也仅使用上述保守上限，不回退到一小时。
- 前端独立限制最多 **5 分钟**，以更早的服务端期限为准；缓存键升级为 `hyhq.theme-assets.v2.`，不读取旧 v1 的一小时缓存，读取已有缓存不延长其期限。
- 保留固定装饰白名单、失败回退和原有图片权限，不新增刷新接口，不记录签名地址或密钥。

上述改动降低复用失效地址的时间窗口；请求的签名时长并非实际可用期保证，最新部署后的重编译及跨缓存窗口返回页面已完成有限样本核对，结果见下方；长期弱网行为仍待真机复验。
