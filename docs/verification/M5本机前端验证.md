## 本次发现并修复的问题

评论页原先把 `wx:if="invalid"` 等条件写成普通属性文字，没有包在 `{{ }}` 中。微信会把非空字符串当作真，因此有效的文章、路线和地点入口仍会一直显示“内容入口无效”，后面的评论内容无法出现。这种语法能通过原生编译，原先仅测试页面 JavaScript 的用例也无法发现。

已修正评论页全部条件绑定，覆盖无效入口、登录状态、功能开关、评论表单、空态、删除/举报操作、分页和举报表单。新增全项目条件绑定检查：先对未修复模板运行，确认在 `wx:if="invalid"` 上失败；修复后重跑全量测试及原生编译，均通过。同时让事件处理函数检查识别 `bind:retry` 一类带冒号的合法写法。
