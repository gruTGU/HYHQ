## 新增的真实 PostgreSQL 并发覆盖

新文件：

- `backend/community/tests_concurrency.py`
- `backend/weatherdata/tests_reminder_concurrency.py`

六项验证均使用独立数据库连接与真实事务：

1. **六个连接重复提交同一评论标识**：只创建一条评论、一次检测和一次请求记录，其余返回已有结果或处理中状态。
2. **五个不同账号竞争最后一个全站检测额度**：仅一个请求成功，其余被限额拦截，日计数恰好达到上限。
3. **内容检查进行中注销账号**：注销成功后，检查迟到结果返回认证失效，不重新生成个人评论或请求记录；匿名调用计数保留。
4. **并发设置并确认天气提醒**：只有一份有效提醒授权。
5. **多个提醒执行器竞争且送达结果不明确**：实际发送只有一次，状态进入待核实，不重复消费一次性授权。
6. **发送期间注销账号**：另一连接使用 PostgreSQL `NOWAIT` 探测证明确实持有账号行锁；注销等待发送及审计事务完成后才执行，并清除个人提醒及发送记录。

这些测试不只是 SQLite 下的顺序模拟，实际使用 PostgreSQL 的行锁、独立连接、唯一约束与级联清理。新测试在不支持行锁的 SQLite 环境会明确跳过。
