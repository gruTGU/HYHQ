- [x] 保存昵称按钮使用固定高度与弹性居中，文字不再依赖原生按钮默认行高。
- [x] 微信登录前增加应用自己的“登录海晏河清”确认弹窗；先阅读勾选协议，再确认登录。取消不取登录凭证，已登录不重复弹窗。头像与昵称继续使用 `chooseAvatar` 与 `type="nickname"`，不把应用确认称为微信身份资料授权页。

- [x] 组件隐藏、卸载后停止接受点击和绘图回调；切换指标、情景后忽略过期的异步尺寸查询结果。

## 交付边界

- 前端改动需要同步到当前生成的小程序工程，并通过开发者工具预览；手机正式版需要上传发布新的小程序版本后才会使用这些代码。单独部署云函数不能更新手机里的页面代码。
- 自动化测试验证逻辑与绘图调用，不替代真机相册、真实微信登录界面和各设备图层效果的验收。
