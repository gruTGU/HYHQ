## 本次发现和修复

- **评论页显示条件**：15 处条件没有使用 `{{ }}` 绑定，合法内容也会一直显示无效入口。已修正，新增结构回归先复现失败再确认修复。
- **健康接口旧版本**：原硬编码 `m3` 改为 `m5`，现有定向测试和重启后的真实 HTTP 核对通过。
- **预览目录刷新**：在已打开的项目上重建目录后，工具保留旧运行状态，出现 `getApp()` 未就绪。清缓存不能恢复，使用“项目 → 重新打开此项目”后正常。生成脚本和说明已提示先关闭预览再生成；没有通过放宽生产配置掩盖问题。
- **两个新入口宽度**：资料检索和天气入口改为整行宽度及合适留白，并提高页面选择器优先级以覆盖微信按钮默认宽度。增量更新后原生编译通过，科普入口整行显示已在模拟器复核。
- **并发回归补充**：新测评论重复提交/最后额度/注销、提醒并发授权/未知送达/发送期间注销；真实 PostgreSQL 行锁检查通过，无需修改业务事务实现。
