## 2. 互动回归重点

- 天气卡跟随实际天气条件换色，未知条件保持中性色，不编造晴天。
- 高级筛选/空气细项/模拟说明展开不额外发请求；隐藏页面后的旧响应不回写。
- 导览图/列表切换保留选中点和缩放；坏图切回可用列表。
- 河湖/数据中心点击指标切趋势，保持来源、场景、批次隔离；缺失值不连线。
- 文章 Markdown 使用现有受限渲染器，不执行任意 HTML 或加载模型外链图片。
- 对话按时间正序显示；上下文不预填进输入框；新问题仍由用户显式发送。
- 长问题、错误提示、键盘展开时，输入区按实际测量高度占位，包含安全区；旧测量不能影响新会话、账号或已隐藏页面。
- 失败问题恢复编辑时不覆盖已有草稿；服务状态不明时禁发并保留草稿。
- 记录空态有实际去向；资料编辑/删除/反馈继续保留身份隔离与确认流程。

## 3. 资源与使用量

- 用户原有品牌 Logo 与绿系图标保留。
- 植物插画使用内置 imagegen 生成，原图保存于 `design/illustrations/`，小程序使用约 197 KB 的本地 JPEG；提示词和路径见 [插画说明](../../design/illustrations/README.md)。
- 全部插画无需请求第三方生成地址；无外链占位图。
- 本批本机首页 HTTP 联调触发和风天气 **3 次**请求（天气、空气、预警，各 1 次），三项均返回 200，已计入既有持久预算；没有修改或清零账本。
- 本批没有创建 AI 问答或调用 DeepSeek。测试不记录真实凭据、令牌或私有图片。

- [ ] 首页、导览、AI 识别、科普智游、个人页五屏外观和底栏安全区。
