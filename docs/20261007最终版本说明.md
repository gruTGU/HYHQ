## 本版内容

### 生态导览

天津、北京继续使用真实地理底图。初始 74 个参考点叠加本次天津文件后，形成 277 个地图点（天津 216、北京 61），新增 203 个具体点。按具体 POI 去重后保留来源资料关联，不把同一条河下多个广场、公园或河岸合成一个假想坐标。

支持城市与分类切换、静态名称标签、点击来源卡、参考点选择器和列表定位。天津工业大学归“校园”，介绍仅“畔湖”；海河记录关联点归“步道地标”。去掉“用户自行添加”等展示文字，校园点使用中性来源说明，腾讯 POI 保留真实来源。

### 问问 AI

选中点位后以该点作为来源；未选点时按当前城市问答。城市入口可以按地点名称、河湖、公园、校园或步道地标检索同城参考点。每次提问从当前已发布目录检索有关文章、路线与地点，以及本次已审天津文件中与命中点关联的资料。

提示词区分点位元信息、父级河流/区域背景、地点专属资料、通用科普、科普模拟和天气缓存。没有匹配的补充文章时，不编造实时环境结论，也不否定点位已有的名称与地址。地图引用可回到对应城市并选中该点；原文章、路线、正式地点引用仍打开详情。保留多轮对话，资料编辑或撤回后重新核对依据。

### 数据状态

本次天津文件的 145 条资料由用户确认已审，旧待审标记不再覆盖该确认。其中 52 条有具体点位关联，93 条无具体坐标；后者仅保留在服务端资料文件，不落点，不伪造地图引用。完整正文不进入小程序前端包，也不自动发布到正式博客。

其他原始 Markdown 稿件保持原审核状态。既有正式地点、文章、路线和用户数据库未因本轮静态资料接入被覆盖。点位坐标已确认不等于公园入口、全河段范围、道路可通行或实时水质测量；参考点不据此开启导航。

## 交付与使用

交付状态以[本轮交付记录](verification/京津地图与私人反馈功能验证.md#地图参考点-ai-交付2026-10-08)为准。打开微信开发者工具的 `HYHQ-personal` 项目，编译后由用户手动测试并上传小程序。云函数更新与小程序正式上传分别进行，本次不代为提交微信审核。

建议手动查看：

1. 天津 → 校园 → 天津工业大学，介绍为“畔湖”；天津 → 步道地标，海河各具体点名称正确。
2. 点击点位 → 问问 AI，围绕当前点提问并连续追问；点击回答来源返回相应地图点。
3. 不选点直接问“天津有哪些河流”“海河相关点在哪里”，确认来源与当前城市一致；切换北京后不残留天津点位。
4. 提问某点当前水质或开放情况，缺少对应材料时不应编造实时结论。

按用户要求，本轮只人工阅读代码和数据转换结果，**未运行自动化测试、编译检查、UI 自动验收或真实 AI 试问**。打包、部署及推送记录不代替应用测试；历史测试数量不属于本版验收结果。
