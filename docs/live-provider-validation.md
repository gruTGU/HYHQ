## 会话、请求与权限复核

复核代码与 10 项后端测试后，在“仅当前电脑回环接口使用”的范围内，未发现尚未处理的高风险身份或越权问题。

- 服务仅监听 `127.0.0.1`。Host 仅允许回环名称；浏览器 Origin 与 Fetch Metadata 拦截外站请求；写请求要求 JSON，不启用跨站 CORS。
- Cookie 使用 HttpOnly、SameSite=Strict 和 `/api/` 路径。随机会话 token 仅以 SHA256 保存；注销立即撤销。失效 cookie 会被清除，私有请求仍返回 401。
- 所有私人对象均按会话绑定的账号再次校验；客户端 OPENID、APPID、Bearer、role 不能建立身份或管理员权限。
- 密码使用随机盐和 scrypt；登录具备账号与来源频率限制。注册必须显式接受协议。管理员只由本机 CLI 初始化。
- 上传按真实图片解码、像素和 5 MiB 上限处理；文件路径由服务端 UUID 生成，浏览器只能通过归属校验后的下载接口获取。
- `.private` 目录为 700；环境配置、数据库及管理员凭据文件为 600。数据目录不在静态网站目录内。
- 管理资料修改使用版本校验、事务与审计；不同普通账号间的图片、识别结果、反馈和草稿越权检查均已通过。
- Markdown 在前端使用 DOMPurify 清理后显示。

## 限制与运行说明

当前属于本机 HTTP 服务，因此 cookie 没有 HTTPS 专用 Secure 标记；它没有作为公网部署做完整验证。不能直接将监听地址改为公网并沿用这一验证结论。

真实天气返回的汇总顶层 `observed_at` 为 null；页面应使用来源数据自身时间字段或明确标注的缓存获取时间，不把缓存时间当作现场观测时间。空预警仅代表本次对应接口的空结果，不是长期无风险结论。

本次计时是单台电脑单次测试，不代表稳定服务时延或高并发能力。LLM 的一次成功不验证长期可用性、全部问题质量或完整模型能力。两个本地 ONNX 模型另已通过真实上传、任务执行和结果隔离测试。

服务进程保留运行供浏览器验证。复测脚本为 `node backend/validate-providers.cjs --run`，明确执行会消耗实际额度；普通后端测试不会调用外部收费服务。
