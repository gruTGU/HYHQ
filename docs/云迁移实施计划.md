- 保留 Django/DRF、PostgreSQL、CPU 推理和现有任务队列。小程序使用 `wx.cloud.callContainer`，原 HTTP 传输保留为显式可选模式；云调用失败不自动转向自建服务器。
- 首期采用 **CFS 持久文件挂载**，保留现有图片净化、私有读取、音频校验和过期清理。对象存储直传暂不纳入本期，避免同时改变账户权限和存储模型。

官方依据：[云调用与小程序关联](https://docs.cloudbase.net/run/develop/access/mini)、[持久文件 CFS](https://docs.cloudbase.net/run/deploy/configuring/storage/cfs)、[PostgreSQL 连接](https://docs.cloudbase.net/database/postgresql/connecting-to-postgresql)。具体账号、地域、CFS 与 PostgreSQL 可用规格仍待实际控制台核实。

## 4. 额度、隐私和回退

- 本期本地测试关闭 DeepSeek、和风和订阅发送，使用现有真实模型做 CPU 推理，无新增供应商 API 消耗。
- 云环境启用天气前，必须重新划分既有本机 100 + 北京 29,900 的同账号总预算，或使用经确认独立计费的账号；不能复制 Key 后再给云环境一份 30,000 上限。热带气旋、海洋、辐照继续排除。
- 后端身份、图片归属和历史删除规则继续有效；云平台关联小程序不能替代业务鉴权。数据库和文件不设为小程序直接公共读取。
- 自建版与云版不共用正在消费任务的业务库。生产切换前停止旧消费者与提醒发送；回退不恢复旧额度、已取消授权或已删除用户数据。
- 此处的并行指版本与研发并行，不是把真实流量自动双写或双调供应商。
