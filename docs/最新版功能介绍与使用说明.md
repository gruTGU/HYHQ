# HYHQ 最新版功能介绍与使用说明

更新日期：2026-09-23。本地最新版包括森系 UI 与公开科普、京津漫步路线补充；北京部署仍为 `d4d0bed`，本批内容尚未同步服务器。

HYHQ 海晏河清智慧平台面向课程、毕设和比赛演示，围绕生态信息、校园科普与绿色游览提供微信小程序和管理后台。主要业务已实现，北京服务器的数据库、依赖、图像推理和外部 API 已完成内部验证。**正式公网使用仍待域名放行、HTTPS、微信登录配置和手机真机验收。**

本文介绍实际功能、操作入口与限制；逐项状态见 [开发目标 TODO](开发目标TODO.md)。旧批次验证记录中的未部署、空 Key 或全模拟描述，只代表当时状态。

## 一、用户端功能与使用方式

小程序底部有五个入口：**首页、生态导览、AI 识别、科普智游、我的**。已使用项目品牌 Logo 和绿色图标，中间 AI 识别入口为突出的圆形按钮。

### 1. 首页与真实天气

在首页“城市与校园天气”选择天津市、天津工业大学、天津师范大学、天津理工大学或北京市，可查看实时天气、温湿度、空气质量、气象预警、来源与更新状态。

- 已接入和风天气，三所大学对应附近区域天气，不代表校内传感器观测。
- 当前手动选择地点；根据定位自动切换城市尚未开发。
- 真实天气卡与虚构示范区域的模拟指标分别展示，过期缓存、请求失败和明确无预警有不同状态。
- 本项目天气请求预算为本机每月 100 次、北京每月 29,900 次，合计最多 30,000 次；天气、空气、预警分别计数。缓存不重复外呼，失败和超时也占预算，另有滚动 31 天限制。达到上限后停止外呼。
- 该限制覆盖项目管理的两套环境，不覆盖在其他工具中直接使用同一 Key 的调用。热带气旋、海洋和辐照接口按要求排除。

### 2. 生态导览

**入口：底部“生态导览” → 选择区域或类型 → 点击地图标记或列表 → 地点详情。**

支持静态示意地图缩放、拖动、点位查看，地点介绍、关联科普和监测数据入口，以及收藏、手动记录游览和右下角“问问 AI”。

本机已补充天津、北京共 70 个有来源的真实地点，采用地点列表，并新增“步道地标”筛选。原有示范校园仍为虚构教学资料；尚未接入真实地图、距离计算和道路导航，真实地点也不代表已经有对应传感器观测。

### 3. 智慧河湖与生态数据中心

**入口：首页“智慧河湖”或“生态数据中心”，也可从关联地点进入。**

按水体、监测站、指标、时间、来源、场景和批次筛选，查看水温、pH、浊度、溶解氧等指标及空气、气象类模拟观测。支持最新值、趋势图、最大/最小/平均值和有效、缺测、存疑数据统计。

正常、浑浊、缺失三种模拟场景可以复现；图表区分缺测与数值 0，保留来源和批次，不拼接不同批次冒充连续实况。已有 CSV 历史导入工具。

**当前展示以模拟观测为主。** 和风实时天气尚未写入这套历史图表，没有实际河湖传感器接入，也不输出完整官方水质等级或综合生态指数。仪表盘使用项目自己的轻量图表，未安装 Superset。

### 4. 花卉识别

**入口：底部“AI 识别” → 登录 → 拍照或选图 → 上传并等待结果。**

已使用真实 CPU 图像模型完成异步识别，展示前三候选、模型分数和关联科普；可保存、查看、删除记录，并进入 DeepSeek 解读。

当前仅覆盖：**雏菊类、蒲公英类、蔷薇属花卉、向日葵类、郁金香类**，不区分具体品种。当前模型尚无有效的未知对象拒识，高分也可能误判范围外图片；校园实拍和非目标图片测试仍需补齐。

### 5. 河道图像观察

**入口：首页河道观察入口，或 AI 识别页 → 河道观察 → 上传照片。**

支持漂浮物实验检测、检测框、数量与框面积相关的教学规则分、可选水体关联、私有历史与 AI 解读。用户可以主动定位后选择附近水体，也可以跳过定位手动选择。

目前仅开放已验证能运行的漂浮物类别。图像规则分不代表正式水质等级，框面积不代表真实污染面积，未检出也不能证明水体干净。塑料瓶细分类、排污口、异常水色和岸带侵占检测尚未形成可用能力。

这部分整合了朋友仓库的河道任务、YOLO ONNX 检测、版本化教学评分、水体关联和记录展示，并适配现有权限与任务机制。没有将朋友仓库全部功能直接搬入，详见 [朋友仓库整合说明](朋友仓库整合说明.md)。

### 6. 科普智游

**入口：底部“科普智游” → 选择“科普手记”或“漫步路线”。**

支持区域、分类、植物标签和标题/摘要搜索，文章阅读、收藏、关联地点及同类科普。预设路线可逐站浏览并跳转地点详情；文章和路线都可以唤起 AI。

本机现有 38 篇公开手记、31 条路线，其中本批新增 30 篇科普及天津、北京各 15 条有来源的漫步参考。已按植物、水环境、绿色生活、生态智游分类；当前若是示范校园，可点击“浏览全部区域路线”或改选天津/北京，查看更多时继续翻页。来源、查看日期和正文均可在详情阅读。

内容由管理员发布维护，公开资料经核读与改写后入库，路线按已知节点整理；搜索不覆盖正文。游览是用户主动记录，尚无到访定位核验，也没有自动路线规划或实时步行导航。

### 7. DeepSeek 场景互动

| 场景 | 入口 | 可用资料 |
| --- | --- | --- |
| 识别结果解读 | 花卉或河道结果页“AI 解读” | 本人识别结果、关联科普；可主动附上有效任务原图 |
| 生态导览 | 导览及相关地点、河湖等页面悬浮 AI | 当前公开地点、水体资料和部分模拟监测摘录 |
| 科普智游 | 科普、文章、路线页面悬浮 AI | 当前文章、预设路线与关联公开资料 |

模型名称显示为 DeepSeek Flash。服务端根据场景拼接背景资料，长正文有长度上限；用户输入框保持为空，只填写自己的问题。打开页面不自动调用模型，点击发送才提交。

已支持常用 Markdown、历史续聊和删除，三个场景分别执行每日额度，页面不常驻显示剩余次数，触限后提示。附图默认关闭，只能使用本人成功且有效期内的识别任务原图，不能作为任意图片或文件聊天入口。

**和风实时天气尚未接入 AI 上下文。** 当前也没有联网搜索、全站知识检索、实时地图查询、语音讲解或本地 Qwen。长回答与完整多轮质量仍需专项评估。

### 8. 我的与反馈

**入口：底部“我的”。**

支持昵称头像、收藏、浏览、游览、花卉识别、河道观察、AI 对话记录，浏览记录开关、退出和注销，以及协议与隐私说明。可提交私人反馈并查看管理员答复；它不提供公开评论社区。

本机开发测试登录可以验证上述流程；生产关闭开发模拟登录，真实微信身份登录仍需补齐 AppSecret 和公网条件后验收。注册/登录与“我的”保留协议入口，业务页无重复勾选；主动选图、可选定位等微信系统授权仍保留。

## 二、管理端怎么使用

本机服务启动后，在浏览器打开 `http://127.0.0.1:8000/admin/`，使用已有管理员账号。管理端目前采用 Django Admin，按账号权限显示可用模块。

| 模块 | 已实现能力 |
| --- | --- |
| 用户与权限 | 用户、角色分组、管理权限 |
| 内容与地点 | 科普文章、标签、路线、地点、河湖、监测站 |
| 生态数据 | 指标、来源、模拟场景和批次，历史导入工具 |
| 模型与规则 | 图像模型登记、启停、回退和历史版本；河道教学规则版本 |
| LLM 网关 | 开关、调用限制、请求状态和 token 记录；凭据保存在后端私有环境 |
| 天气 | 地点、缓存、请求账本和预算查看 |
| 反馈 | 查看、回复并更新处理状态 |
| 统计与审计 | 统一日期和数量口径、权限内查询、关键管理变更记录 |
| 模拟维护 | 保留策略、清理预览、确认维护、并发保护与命令工具 |

常用入口：

- 管理统计：`/admin/common/managementstats/`，按北京时间选择查询范围，区分当前存量与窗口内新增。
- 操作审计：`/admin/common/auditlog/`，查询操作者、时间、对象与动作；不记录密钥或字段正文。
- 模拟维护：`/admin/ecology/simulationrun/maintenance/`，先预览待清理范围，再确认执行。默认保留 30 天、每来源/场景至少三个最新成功批次，同时保护每站最新数据等必要记录。

模拟维护工具已完成，**定时自动删除模拟批次尚未启用**。服务器每日私有文件清理属于另一项运维任务。管理端也尚无独立定制的大屏或拖拽式 BI。

## 三、哪些是真实数据，哪些是模拟或实验结果

| 内容 | 当前性质 |
| --- | --- |
| 首页天气、空气质量、预警 | 和风真实 API，可能展示有明确时间标识的缓存 |
| 智慧河湖与历史环境图表 | 主要是可追溯模拟观测，支持导入但未接通真实河湖源 |
| 花卉识别 | 真实模型推理，范围限定为五类 |
| 河道观察 | 真实漂浮物实验检测与教学规则分 |
| DeepSeek 回答 | 真实外部 API 生成，基于受限上下文，不能保证结论正确 |
| 生态地图与路线 | 静态示范点位与管理员编排的路线 |

## 五、尚未开发的主要能力

- 垃圾分类识别，以及更广泛的植物类别。
- 高德/百度实际接入、真实地点搜索、道路导航、自动路线规划与定位核验打卡；已完成 [接入调研与 G01–G06 拆分](高德与百度数据接入方案.md)。
- 真实水环境监测设备或第三方河湖数据源、完整综合生态指数和趋势预测。
- 天气预报页面、订阅消息和主动提醒。
- 全站资料检索问答、AI 实时天气/地图工具、语音讲解、多模型自动切换及本地轻量 LLM。
- 用户投稿、公开评论与举报审核社区。

上述增强项按需求选择实施；热带气旋、海洋、辐照属于明确排除范围，不列为待补齐能力。

## 六、建议后续开发顺序

1. **正式使用验收**：域名、HTTPS、微信登录与合法域名 → 手机完成浏览、上传、识别、问答、记录和注销 → 备份与运行稳定性验证。
2. **真实校园地图**：核对天津三所大学及出入口 → 选定一家供应商 → 受控地点查询、地图与步行路线 → 坐标和预算验收。
3. **真实数据与 AI**：天气上下文和可核对来源 → 历史数据展示 → 有可靠来源后接入真实河湖指标。
4. **识别与体验提升**：补充代表性实拍、未知对象处理 → 评估扩展类别 → 完善交互和演示材料。

地图开发时仍可并行准备实拍数据；公网条件未就绪时，可先做不依赖它的本地完善项。具体任务及验收条件统一维护在 [开发目标 TODO](开发目标TODO.md)。
