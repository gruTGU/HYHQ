# 独立网页版功能清单与适配边界

核对日期：2026-10-08。本项目以微信云版 `1080ad3` 的公开资料、模型及主题为基线，在 `/Users/liu/Desktop/hyhq` 独立演进；正式网页已部署到 [greatdata.asia](https://greatdata.asia)。网页使用独立 SQLite 和私有文件存储，未导入小程序用户或私有数据。当前小程序另有关闭生成式问答的特别版本，不能把网页功能清单当作小程序最新版功能。

## 3. 网页端适配

### 账号和私有数据

- 旧微信用户、OPENID、云会话、头像、照片、收藏、浏览、足迹、反馈、草稿、AI 对话、预约及权限**没有迁入**。用户可建立独立网页账号或进入游客体验；云端私有数据仍独立保存。
- 注册/登录使用官方 ALTCHA 自托管挑战：五分钟有效、用途/IP绑定、事务一次性消费及持久限流；协议默认不勾选，密码不trim。
- 普通账号注册不能授予管理权。本机管理员由初始化工具建立，凭据仅存本机私有目录。
- 私有请求使用 HttpOnly 会话 Cookie。上传图片保存在静态网站目录之外；预览经本人归属检查的接口读取为临时 Blob，切换账号或离页会释放。
- 原图默认 24 小时，任务与识别缩略图默认 30 天；选作头像后保留至更换或注销。会话与任务的删除关系沿用原业务规则。
- 游客随机会话只代表本人临时资料归属，IP的HMAC摘要只用于额度。共享网络会共享识别/AI额度，不能据IP访问他人的私人对象。
- 账号注销清理私人对象；匿名限额记录与必要管理审计按原保留规则存在，不能通过删账号重置服务预算。

### 天气预算与后台抓取

- 当前分配：**小程序云端15,000次/月 + 生产网页15,000次/月**，合计30,000。云函数环境变量已保存并重新打开确认；既有用量账本保留，自然月与滚动日桶均受限。
- 网页仅后台抓天津、北京，实况/空气/预警每小时、预报每六小时；正常成功调度约4,712次/31天，重试也计入总上限。浏览、手动刷新、预约和AI上下文只读数据库缓存。
- 本机网页后台抓取关闭，当前本机后端已停止；旧本地不再保有额外独立天气额度，不得再另起进程使用同一Key抓取。缺缓存时显示不可用，不越过调度直接外呼。
- 热带气旋、海洋、辐照不在允许接口范围。

### 浏览器权限和交互

- 小程序相机/相册改用浏览器文件选择与 `capture`，是否调用系统相机取决于浏览器设备。格式、体积、像素和真实解码均会校验；不在上传区域恢复已经删除的格式/体积宣传行，非法文件才显示对应错误。
- 微信原生地图改为浏览器地图与受控导航链接；没有自动定位、轨迹采集或模拟到访认证。
- 微信订阅消息改为本机站内通知。服务运行时处理到期任务；重启后补生成尚未处理通知，不声称关闭服务期间实时推送。
- 小程序的页面跳转与触底加载改为路由和明确分页按钮；私密列表在账号变化后清空，分页限制为本源对应接口。
- 桌面侧栏、移动底栏、对话浮层和四套主题共用业务能力。原来的账号与数据权限不会因主题改变。

## 5. 文案与视觉约束

- 不恢复此前删除的纯介绍段落、页面口号、旧入口和上传格式/体积提示行。

- 五类花卉完整范围解释始终展开；不能折叠或改写成能识别所有植物的承诺。
- 保留必要的模型适用范围、图片质量与未知结果提示；只在真实模型结果允许时展示候选、分数和摘要。

- 四套主题为森系自然、纪实自然志、山水测绘册、深色模式。主题变化不恢复已删文案，不影响账号隐私与真实能力状态。
