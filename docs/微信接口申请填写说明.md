# HYHQ 微信接口申请填写说明

核对日期：2026-09-23。按当前实际代码填写，适用于个人主体的 HYHQ 海晏河清智慧平台；接口能否开通仍以本账号已审核类目和微信后台显示为准。

## 1. 当前应该申请哪个接口

**当前需要核实并申请的是 `wx.getLocation`，请把申请页中的 `wx.chooseLocation` 切换为 `wx.getLocation`。**

- `wx.getLocation`：获取用户当前的位置。项目在“河道观察”页的“可选：获取位置并查找附近水体”按钮中调用，使用 GCJ02 坐标。
- `wx.chooseLocation`：打开地图，让用户选择一个地点。项目当前没有调用，没有对应地图选点页面，暂不申请。
- 首页天气当前手动选择预设城市/校园，不调用定位。生态导览是静态示意图，游览记录由用户自记；这些功能不能写成实时导航、定位选城或到访打卡的申请理由。

官方 `getLocation` 文档要求先满足相应服务类目条件，再申请接口。小程序备案通过不等于接口权限已开通；如果后台没有 `getLocation` 可申请入口，先核对自己的主体、已通过类目和后台说明，不用 `chooseLocation` 替代。

代码依据：[河道观察定位调用](../miniprogram/pages/assessment/index.js)、[按钮和记录展示](../miniprogram/pages/assessment/index.wxml)、[app.json 声明](../miniprogram/app.json)。官方说明：[getLocation](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.getLocation.html)、[chooseLocation](https://developers.weixin.qq.com/miniprogram/dev/api/location/wx.chooseLocation.html)。

## 2. 接口清单：申请与隐私声明分开填写

| 接口或能力 | 当前用途 | 当前需要办理的内容 |
| --- | --- | --- |
| `wx.getLocation` | 用户主动查询附近已登记水体，可将本次位置附在私人河道观察记录中 | 核对类目并申请接口；隐私指引声明位置信息；保留用户授权与拒绝后的替代操作 |
| `wx.chooseMedia` | 拍照或从相册选择花卉、河道照片 | 按隐私指引声明“选中的照片或视频信息”，用途明确当前只选择图片；不属于本次定位能力申请 |
| `button open-type="chooseAvatar"`、`input type="nickname"` | 用户主动设置昵称和头像 | 隐私指引声明昵称、头像；当前没有调用 `wx.getUserProfile` |
| `wx.login` | 登录后保存私有记录、上传图片、使用 AI | 配置实际 AppID 和服务端 AppSecret，验证登录；不用填写定位接口申请理由 |
| `wx.request`、`wx.uploadFile`、`wx.downloadFile` | 访问后端、上传及读取私人图片 | 配置对应合法域名、有效 HTTPS；不用为每个网络接口另写定位申请 |
| `wx.chooseLocation`、模糊定位、连续/后台定位、手机号、支付 | 当前未使用 | 暂不申请，也不把这些能力写成已实现 |

`chooseMedia` 的拍照入口不等于项目使用麦克风、相册写入或后台相机。按实际调用和微信后台检测结果选择隐私项，不扩大声明范围。DeepSeek 和和风由后端调用，不需要把它们当作微信定位接口申请。


### 申请接口理由（可复制，213 字，含标点与英文）

```text
HYHQ海晏河清提供河道照片观察与个人记录功能。用户在“河道观察”页主动点击“可选：获取位置并查找附近水体”后，调用wx.getLocation单次获取当前位置，用于查询平台已登记的同坐标系附近水体候选，帮助用户确认本次观察对象；提交照片时，可将位置随本人观察记录保存。仅凭照片或水体名称难以区分不同河段，因此需要位置辅助关联。用户可拒绝定位或清除位置，仍能手选水体或直接上传；不持续定位、不采集轨迹，记录仅本人可见并可删除。
```

**提交前条件：** 这段说明对应已有代码，但当前水体目录主要是教学示范资料。申请“附近水体”场景前，应核对目标区域已登记的真实水体/站点及 GCJ02 坐标，并用真实运行页面展示匹配或明确无候选的结果。没有真实点位时，应如实保留示范说明，先补资料和验证，不把虚构水体写成当地实测站，也不承诺审核通过。

当前位置记录的是用户点击时所在位置。对相册旧照片，不能据此声称取得了原始拍摄位置；当前系统不从照片 EXIF 还原位置。

## 4. 用户隐私保护指引可用文案

这些内容填写在微信后台的“用户隐私保护指引”，不是把所有内容都放入定位申请理由。后台字段名称以当前页面为准。

| 数据类型 | 可复制的实际用途 |
| --- | --- |
| 用户位置信息 | 仅在用户主动点击河道观察页的获取位置按钮后，获取本次位置并查询附近已登记水体候选；用户提交观察照片时，可将位置随本人观察记录保存。用户可拒绝或清除位置，仍可手选水体或直接上传，不进行连续定位或轨迹采集。 |
| 用户选中的照片或视频信息 | 用于用户主动选择的花卉和河道照片识别。当前仅选择图片，不选择视频；经用户主动选择附图时，可将本人有效识别任务的处理后图片用于 DeepSeek 结果解读。 |
| 剪贴板（仅写入） | 用户主动点击首页“复制来源链接”后，将和风天气的公开网址写入系统剪贴板，方便用户自行访问来源。不读取、不上传剪贴板内容；对应 `wx.setClipboardData`，按微信后台隐私检测结果声明。 |
| 用户昵称、头像 | 用于展示用户主动设置的个人资料，区分本人账号和私人记录。用户可修改资料或注销账号。 |

已有收藏、浏览、反馈、AI 对话等业务记录也应在实际隐私说明中如实列明。运营主体、联系方式、实际保留期限以及 DeepSeek 等外部处理情况需对应实际填写；页面已去除工程占位提示；运营者身份、对外联系方式和备份删除期限仍保留在发布清单待补，不能将界面改版视为已完成全部发布材料。

接口开通、后台隐私声明、微信隐私授权同步和系统位置授权属于不同环节。“注册即同意”的业务文字不会自动完成微信平台的隐私授权，微信官方授权提示仍可能出现。

官方依据：[隐私数据与接口映射](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)、[隐私授权同步](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)、[chooseMedia](https://developers.weixin.qq.com/miniprogram/dev/api/media/video/wx.chooseMedia.html)、[登录流程](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)。
