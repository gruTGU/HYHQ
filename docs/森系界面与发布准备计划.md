## 2. 视觉规范

- 背景 `#f0f4ed`、主色 `#3a7d5c`、嫩芽 `#a8c99b`、湖水 `#7fb3c8`、正文 `#2c3e33`、温和提示 `#d97b4f`。
- 一级主操作突出，资料说明和高级筛选按需展开；模拟属性与来源不折叠隐藏。
- 小字优先保证可读性；操作带文字，不依赖颜色或插画区分功能；按钮保留按下反馈。
- 装饰插画随包发布，不请求第三方图片生成服务；原始图及生成提示见 [插画说明](../design/illustrations/README.md)。
- 页面公开内容可直接看；收藏、识别、个人记录与 AI 需要真实登录。拒绝可选定位仍可继续观察。

## 3. 本机使用方式

1. 启动本地后端及所需工作进程，确保 `http://127.0.0.1:8000/api/v1/health/` 可用。已有本机环境可使用 `.runtime/local-test/启动本地测试.command`。
2. 在项目根目录运行 `node scripts/prepare-miniprogram-preview.mjs`。
3. 微信开发者工具导入根目录下生成的 **`miniprogram-preview`**，仅用于本机预览。每次源码变化后重新生成；不要手工修改生成目录。
4. 生成副本固定连接 `127.0.0.1:8000`、关闭开发登录；它不拷贝后端环境变量或 API Key。开发登录/账号业务的临时测试需单独在本地测试流程中使用，不能混入发布代码。
5. **不得上传 `miniprogram-preview`**。发布来源始终是 `miniprogram`：HTTPS、域名校验开启、开发登录关闭。公开仓库保留示例 AppID，实际 AppID 在本机私有配置中。
6. 真机上的 `127.0.0.1` 是手机本身；当前副本仅用于电脑开发者工具，不等于真机公网联调已通过。

本地编译检查：`node scripts/check-miniprogram-compile.mjs`，直接使用已安装微信工具的 WXML/WXSS 编译器，不要求开启工具服务端口，不执行预览上传或提审。非默认安装位置可用 `HYHQ_WECHAT_COMPILER_DIR` 指向编译器目录。

- [ ] 安卓及 iOS 完整流程：公开浏览、登录、上传、花卉/河道识别、AI、记录/删除、隐私开关、退出/注销；检查键盘、图片权限拒绝和弱网错误。

页面变得完整不代表自动获得平台审核通过。核对依据为微信 [运营规范](https://developers.weixin.qq.com/miniprogram/product/index.html) 与 [常见拒绝情形](https://developers.weixin.qq.com/miniprogram/product/reject.html)：功能应能正常运行，入口与说明一致，用户应有可用的返回/退出和隐私选择。保留明确用途的科普模拟内容，不等于可以提交无法工作的测试壳；最终仍由平台审核。
