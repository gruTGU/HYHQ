# 网页端：地方活动与环境反馈 · 2026-10-19

## 实施范围

本轮基于正式网页版独立开发，保留地图、天气、识别、博客与四套主题。小程序有单独的实现及 Git 分支；比赛本地演示版不在本轮范围内。

### 地方活动

- [x] 京津全年花季模拟日历，按月份查看。
- [x] 首页和“我的”提供活动入口，地图选中具体点位展示近期活动；没有安排的点位显示近期无活动。
- [x] 登录后首次询问站内活动提醒偏好；关闭后不再自动弹出，可随时重新开启。
- [x] 开启后每日最多展示一次今日与近期活动，后端按北京时间防止重复。
- [x] 按活动订阅、取消和查看我的订阅。

所有活动均是功能演示排期，不代表真实花展、开放公告或当地花期。不发送浏览器推送或微信消息；原有天气提醒独立保留。

### 环境反馈与模拟上报

- [x] 花卉、河道识别成功结果页提供环境反馈入口。
- [x] 用户核对本人照片缩略图、选择目录地点、填写可见情况后提交。
- [x] 模拟上报进入管理员私密队列；用户查看状态和答复，管理员核对、答复并记录审计。
- [x] 同一识别记录相同内容重复提交返回原记录，冲突内容明确拒绝；限制每日提交量。
- [x] 检查任务归属、登录状态和图片有效期；注销清理私人记录，删除原图或到期后停止展示缩略图。

页面和回执明确标注“未向政府部门发送”。当前没有政府接收渠道，也不将花卉类别、漂浮物候选框转成真实水质或污染结论。地点由用户选择，不能据此证明图片确实拍摄于该地。
