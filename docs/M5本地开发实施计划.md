## 测试与交付原则

- 模拟供应商响应只验证协议和失败处理，不当作真实模型质量或真实账单证据。
- 真实 API Key 不回显、不进入代码；不新增订阅服务、不购买额度、不改变现有预算。
- 外部条件或网络不可用时，完成不依赖它们的代码与测试，留下明确可复核的待验条件。
- 在原有工作区继续，保留上批公开内容；只做必要依赖变更，不整体升级框架或搬入未验证模型权重。
- 完成后更新本计划、开发目标 TODO 和验证报告，列出已实现、可本地体验、保持关闭与尚未完成的范围。
