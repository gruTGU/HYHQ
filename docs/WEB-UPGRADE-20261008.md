## 实施边界

- ALTCHA 开源验证不产生第三方验证码调用费用；消耗自有服务器和访客浏览器的计算资源。此项不等于邮箱/手机验证码，不把未验证的邮箱标为已验证。
- IP 额度由后端和数据库实施；Nginx 覆写转发地址，后端仅在显式配置的回环代理下信任该地址。共享网络会共享游客额度。
- DeepSeek 全站费用预算保持不变。按用户确认，天气上限重新分为网页生产 15,000 次/月、云小程序 15,000 次/月；本机后台抓取关闭。
- 用户明确允许非空短密码。本轮保留加盐哈希、安全 Cookie、验证码与限流，不记录明文密码。
- 网页博客由管理员人工审核发布，不伪造微信内容安全接口已通过，不直接发布用户待审稿。
