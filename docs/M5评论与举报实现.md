# M5-07 评论与举报实现与开放条件

更新：2026-09-24。实现已完成，当前保持默认关闭。本轮仅本机 SQLite、HTTP 测试客户端和前端 mock 验证，没有调用真实微信内容安全接口、上传小程序、提交 Git 或部署。

## 1. 官方范围核对结论

2026-09-23 实际读取以下微信官方页面。原 `OpenApiDoc` 地址会跳转，新文档路径如下；web 阅读工具返回错误后，通过 HTTPS 读取官方正文核对：

- [小程序开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material/)：个人主体列表没有“社交—社区”；教育信息展示强调信息展示，部分工具明确排除原创内容传播或公开访问。**不能据此认定当前个人主体账号可以公开用户评论。** 是否允许具体业务要以该账号的平台类目和平台核实结果为准。
- [文本内容安全识别 msgSecCheck](https://developers.weixin.qq.com/miniprogram/dev/server/API/sec-center/sec-check/api_msgseccheck.html)：接口在服务器调用，评论使用 `version=2`、`scene=2`、微信 `openid`；用户需要在近两小时访问过小程序，返回 `pass/review/risky` 建议。接口可用不代表个人主体拥有公开评论业务资格。
- [获取稳定版接口调用凭据](https://developers.weixin.qq.com/miniprogram/dev/server/API/mp-access-token/api_getstableaccesstoken.html)：服务器通过 `stable_token` 获取令牌，采用普通模式，禁止把凭据放入前端。

这是一项带有明确开放条件的完整功能，实现通过不等于资格审核通过；本项目没有伪造或预先确认主体资格。

## 2. 已完成的业务

- 对已发布文章、路线、地点发表评论；仅普通文字，1–500 字，过滤标签和不可见控制字符。
- 先在服务器调用微信文本安全检测。`pass` 进入人工待审核；`review/risky` 记为未通过，管理员不能强制绕过检测通过约束。
- 审核通过后公开；待审核和未通过仅本人及具有后台权限的审核员可见。下架关联对象后，对应评论从公共列表及个人列表隐藏。
- 评论不支持原地编辑，作者可确认删除后重新提交。删除是服务端按当前账号授权；注销账号级联清除本人评论、举报、请求标识与限频记录。
- 举报公开文章、路线、地点、已审核通过的评论。支持分类原因和 300 字以内的私密说明。不能举报隐藏对象，也不能从举报接口探测其他人的未审稿。
- 同一用户对同一对象只创建一条举报，重复提交返回原记录，不反复占用次数。
- 后台分别维护待处理、已处理、不予受理；评论审核与举报处理记录操作员、时间和内部备注，内部备注不回传普通用户。
- “我的评论”“我的举报”分页记录；服务关闭后本人仍能查阅个人记录、删除本人评论。本人评论列表不会暴露已下架的父对象，举报列表不返回父对象信息。
- 微信检测和人工审核分开；公开作者显示中性的“生态同行者”，避免未经本模块审核的昵称或头像成为公开内容旁路。
- 评论页不预填内容，不自动投稿，不新增隐私勾选弹窗；页面告知评论文字会用于微信安全检查和人工审核。

举报处理本身不会自动删除被举报文章、路线或地点。审核员应先核实，再通过相应内容管理页更正或下架，最后记录举报处理结果。

## 3. 必须同时满足的服务端开放条件

| 条件 | 位置与核对方式 |
| --- | --- |
| 部署总开关 | 环境变量 `COMMUNITY_ENABLED=1`；默认 `0` |
| 管理员显式启用 | 管理后台“评论开放条件”的“管理员启用” |
| 个人主体当前业务范围核实 | 资格确认项、平台核实记录/工单依据、核实日期必须齐全；日期不能晚于今天 |
| 人工审核可运行 | 审核流程就绪，指定有效、启用中的 staff 账号，且具有评论与举报修改权限 |
| 微信内容安全可运行 | 配置服务器微信 AppID/AppSecret；显式安全核验命令成功后生成只读证明，绑定当前凭据摘要，七天内有效 |

接口每次查询状态、公共读取和发布均检查以上条件，不能仅通过修改前端显示开放。管理员审核通过评论时也复查条件、父对象发布状态和该评论微信检测结果。

后台资格记录是运营者依据平台核实情况录入的记录，并非程序代替微信作出的资格认证。没有真实核实依据时，不填写确认，不启用。令牌、AppSecret 不回传客户端，不写审计日志。核验记录只保存不可逆摘要及成功时间。

未来在确已具备资格、环境与人员就绪后，由运营者主动运行：

```bash
python manage.py verify_community_safety --user-id <最近已访问小程序的微信用户UUID>
```

该命令会真实调用一次微信接口，并纳入本模块的日调用计数；不是本轮验证所需操作。成功不会自动打开其余开关。核验失效、凭据变更或审核员停用后，服务停止开放。

## 4. 防重复、限频与隐私

- 评论/举报使用 UUID `request_id` 防止提交后网络断开引起重复创建。相同投稿标识不能用于不同内容。
- 评论每用户每日最多 10 次尝试，每分钟最多 1 次；举报每用户每日最多 20 次，每分钟最多 1 次。失败的外部评论检查也占尝试次数。
- 微信安全检查在调用前登记：本模块（包含显式核验）每日最多 **80 次**，按北京时间自然日统计，为未上架小程序官方 100 次/日限额留余量。此上限不涵盖其他系统使用同一 AppID 的调用。
- 全站安全调用量保存在匿名日计数表，无账号或正文。删除评论、删除个人请求记录、注销账号不能重置全站调用量。
- 创建和审核使用事务、锁定配置与账号；外部请求完成后再次核对账号、功能状态与目标发布状态，避免请求期间注销或下架后仍写入。
- 微信结果、密钥、OpenID、正文、举报说明、内部备注不写入审计。审计只记录业务编号、状态、来源与字段名；管理员审核带模型标签以便按类型筛选。
- 微信请求固定 HTTPS 官方地址、限制响应大小、设置超时、拒绝跳转。失败提示使用固定文案，不回显上游 URL 或错误正文。
- 小程序切换账号、续期 token、隐藏/卸载页面时清理私人草稿和记录，过期列表/删除确认/提交回调不回填新账号。

## 5. 接口约定

均位于 `/api/v1/`。正文与列表继续使用项目统一 envelope 和分页。

| 方法 / 路径 | 功能 |
| --- | --- |
| `GET community/status/` | 公开状态 `enabled/reason/max_comment_length`；不暴露具体凭据与资格证据 |
| `GET community/comments/?kind=content&target_id=<UUID>` | 当前目标的公开评论，加当前用户自己的待审核/未通过评论；游客仅公开评论 |
| `POST community/comments/` | 登录后提交 `kind,target_id,body,request_id`；kind 为 content、route 或 place |
| `GET community/comments/mine/` | 本人评论记录；即使服务关闭仍可读取，隐藏父对象不返回 |
| `DELETE community/comments/<UUID>/` | 本人删除；即使服务关闭仍可使用 |
| `GET community/reports/` | 本人私密举报记录 |
| `POST community/reports/` | 提交 `kind,target_id,reason,detail,request_id`；kind 额外支持 comment |

举报原因：`spam`、`abuse`、`privacy`、`inaccurate`、`other`。`detail` 选填。

常见服务码：`COMMUNITY_DISABLED`、`COMMUNITY_RATE_LIMITED`、`COMMUNITY_DAILY_LIMIT`、`CONTENT_SAFETY_UNAVAILABLE`、`WECHAT_RELOGIN_REQUIRED`、`SUBMISSION_ALREADY_RECEIVED`、`SUBMISSION_FAILED`、`IDEMPOTENCY_CONFLICT`。

网络结果不明确时保留原 request_id，可刷新或重试核对；服务器已明确告知未产生评论的安全检查失败时，前端下一次提交使用新标识，但仍受限频限制。

## 6. 页面与后台使用

- 详情页在 `community/status/` 确认可用时显示入口：`/pages/comments/index?kind=content|route|place&id=<UUID>`。
- 个人评论入口：`/pages/comments/index?mode=mine`；个人举报入口：`/pages/comments/index?mode=reports`。
- 前端直接打开关闭中的评论页会显示“评论与举报暂未开放”；服务端同样拒绝公共投稿和读取，不存在仅隐藏按钮的情况。
- “用户评论”后台按状态/微信检测状态筛选，只能改变审核状态和内部备注，不能改写用户正文、用户身份、微信检测结果。
- “用户举报”后台按状态筛选，只能处理状态与内部备注。只读工作人员不能审核。
- 内容使用原生文本展示，不渲染用户 HTML 或 Markdown，长文自动换行。

后台运营仍需在真正开放前，把评论安全处理与举报处理说明同步至正式注册时适用的协议/隐私政策及微信平台隐私声明；不在评论过程中新增重复勾选框。

## 7. 集成与迁移

公共文件由主任务接入：

1. `INSTALLED_APPS` 加 `community`。
2. `/api/v1/` 加 `include('community.urls')`。
3. settings 从环境读取 `COMMUNITY_ENABLED`，默认 `0`。
4. 小程序注册 `pages/comments/index`，详情/个人入口依照上节接入。
5. 执行正常数据库迁移：`community/0001_initial.py`、`0002_safetyday.py`。不会自动创建已启用配置或验证记录。

账号注销已有 `User.delete()` 事务和关联级联，不需额外修改 accounts；该路径已通过 HTTP 测试验证。
