## 地图数据

使用文件内的 GCJ-02 原始坐标，地图接口统一记为 `GCJ02`，不重复转换。腾讯 POI ID 保持字符串。按来源记录 ID 稳定合并，不按数组位置覆盖已有点位；原有天津工业大学“畔湖”点位保留。

新增点位与现有地图参考点共用城市筛选、名称搜索、点选与 AI 地点上下文。仅校区身份和地址资料进入上下文，不推定校园开放、校门入口、导航路线或实时环境。

本轮不新增文章，不修改用户数据库、账号或服务凭据。
