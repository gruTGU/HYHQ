# HYHQ 原创示范底图

`demo-campus-v1.png` 是 HYHQ 项目原创的 **1000 × 700 像素虚构校园示意图**，没有使用地图服务截图、地理瓦片、卫星图、外部素材或真实经纬度。图中的形状由项目绘图代码生成，可随本项目使用和修改。

- 区域：`demo-campus`，必须为 `is_demo=true`。
- 布局：该区域的 `MapLayout.version=1`；尺寸为 `1000×700`。
- 相对点位：`backend/ecology/management/commands/seed_demo.py` 中的 12 个 `PLACES`。清溪 `(0.26,0.48)`、镜湖 `(0.64,0.36)`、湿地 `(0.79,0.22)` 等均按这组虚构关系绘制。
- 点位编号和名称由小程序读取 API 后叠加；未烘焙进底图。绘图代码不含字体依赖。
- 不代表任何真实校园，不支持地理定位、测距、导航或到访核验。页面始终标明“虚构示范”“静态示意 · 非 GIS”。

## 复现与检查

从项目根目录执行（使用现有后端依赖中固定版本的 Pillow，无新增依赖、无需联网）：

```sh
.venv/bin/python scripts/generate-demo-map.py
.venv/bin/python scripts/generate-demo-map.py --check
```

脚本先从 Python AST 读取 `PLACES` 并检查 12 个相对坐标一致，再绘制并生成 PNG。改变点位关系、图形内容或尺寸时应建立新布局版本和新图片文件，不能覆写已有地点绑定的底图版本。

## 小程序包体优化（2026-10-07）

发布资源改用 `demo-campus-v1.webp`（93,472 字节），与原 PNG 只读解码后逐像素一致，尺寸仍为1000×700。原 PNG 保留供复现，但已从小程序打包列表排除。接口继续返回原登记路径，小程序只对同一区域/版本/尺寸映射到该 WebP；没有替换地点、坐标或地理含义。重新生成原 PNG 后需同步生成无损 WebP 并核对像素、尺寸。

## 客户端边界

本地图片只允许上述区域、虚构属性、尺寸和版本绑定。其他布局需要各自的 HTTPS 图片，不会借用此图。图片实际尺寸与配置不符或加载失败时，隐藏图片和点位并保留地点列表。外部 HTTPS 图片也需在微信平台配置合法下载域名，再用开发者工具及真机检查。
